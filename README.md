## 三个概念先拆开：机房 IP、原生 IP、双 ISP 住宅 IP

普通 VPS 给的是机房 IP。这类 IP 段被大量机器共用，TikTok、亚马逊、Netflix 这些平台早就把大半个段拉进名单了，你新开一台机器，IP 可能一出生就带着“数据中心”标签。

原生 IP 往前走一步：IP 段的注册归属地和机房实际所在地一致。洛杉矶机房分到洛杉矶的段，平台按地域判定时认为你是“本地人”，Netflix、ChatGPT 这类按 IP 判地域的服务，解锁率就上来了。

双 ISP 住宅 IP 再往前走一步：除了归属地正确，它在 ASN 和 Company 字段上还被识别为 ISP 类型、归属住宅宽带运营商。风控系统看到的画像从“一台服务器”变成“一个家庭宽带用户”，账号运营、电商养号这类场景对这点特别敏感。

需要分清的是，**双 ISP 通常同时是原生 IP，但原生 IP 不一定是双 ISP**。市面上不少套餐标着“原生 IP”，检测工具里 ASN 那一栏写的还是机房，两者不是同义词。

## 9929 和 4837 是线路，跟 IP 类型不在一个维度

很多人把“9929 原生 IP”当成一个整体概念，其实是两件事拼起来的。

AS9929 是联通的 CUII 精品网，地位大致相当于联通版的 CN2 GIA：回程强制走这条精品通道，再分送给电信、移动、联通三网，绕路少、晚高峰丢包低。它解决的是“从国内连过去稳不稳”。

AS4837 是联通的普通国际线路。带宽给得大、价格压得低，但优化程度不如 9929，晚高峰的表现要看运气。

一句话区分：**9929 买的是回国质量，4837 买的是带宽单价**。同价位的两个套餐，9929 那边可能只给 50Mbps，4837 那边能给 300Mbps，但后者晚高峰不一定扛得住。做 TikTok 直播、需要盯着后台数据的，9929 更合适；跑批量上传、多账号同时在线、对延迟不敏感的，4837 更划算。

## 买之前必须知道的几个限制

**新机器 SSH 不是 22 端口。** 采用随机端口，得登录控制面板查。连不上先别急着开工单，八成是端口没看。

**9929 部分 IP 段禁 ping。** 这是 IP 提供方要求的，ping 不通不代表机器挂了，正常用不受影响。习惯先 ping 再判断的人容易误判。

**移动用户要挑段。** 美国 38 段和 154 段的产品，移动去程方向有一些拥堵，电信和联通用户不受影响。移动宽带的话选 70 段或 64 段，或者开工单要求换。

**退款条款有前提。** 官方条款是服务开通 48 小时内取消可全额退款，但带宽超分配 5% 或 20GB（取较小值）、有滥用行为、已产生安装费或支付处理费的情况除外；48 小时后申请个案处理。VDS 这类静态住宅托管产品只退网站余额，下单前分清 VPS 和 VDS。IP 若在黑名单内，开通 24 小时内可免费更换，超时换 IP 收费。

**双 ISP 不是解锁保证书。** 流媒体和社媒的风控是动态的，某个 IP 段被大量滥用后可能临时降级。买之前最好先用低配套餐或日付试用验证一遍，别一上来就年付高配。

**新加坡和部分欧洲节点不是大陆直连优化。** 新加坡那条线官网明确建议香港或日本中转；英国、德国走的是国际线路，国内方向稳定性官方没承诺。拿来跑本地业务没问题，拿来当回国主力会失望。

## 常见问题

**双 ISP 和原生 IP 是一回事吗？**
不是。原生 IP 说的是归属地和机房一致，双 ISP 说的是 ASN 和 Company 字段被识别为 ISP 类型、归属住宅宽带运营商。双 ISP 一般同时满足原生，反过来不成立。

**9929 和 4837 到底怎么选？**
看你是被“慢”折磨还是被“贵”折磨。晚高峰卡、丢包、后台刷不动，选 9929；只是嫌流量不够、带宽太小、上传太慢，选 4837。同价位下 4837 给的带宽是 9929 的六倍，代价是线路优先级低。

**68 元和 88 元的套餐差在哪？**
带宽从 50Mbps 到 60Mbps，月流量从 1000GB 到 2000GB，硬盘从 10G 到 20G，CPU 内存都是 1 核 1G。多 20 元买的是流量和一点带宽，配置本身没变。流量每月用不到 800GB 的人，68 元那档就够。

**年付划算还是月付划算？**
年付折合月价普遍比月付低三到四成，比如 9929 双 ISP 年付 41.6 元/月，比月付 68 元省 26 元。但年付是把风险一次性押上，第一次用这家、或者不确定 IP 段适不适合你的业务，先月付跑一周再转年付更稳。有 48 小时退款兜底，但退款条款有前提，别把它当无条件退货。

**移动宽带能用吗？**
能，但避开 38 段和 154 段。选 70 段或 64 段，已经开了不对的段可以提工单换。

**能装 Windows 吗？**
新加坡原生 IP 那条线官网明确写了支持安装 Windows；美国 9929、4837 这些线路的资料里没提，下单前直接问客服确认，别默认所有套餐都能装。
